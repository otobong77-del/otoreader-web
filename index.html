OtoReader

One-time setup

OtoReader reads the same Google Drive folder your phone syncs to. Google requires a free OAuth client ID before any website may open your Drive. It takes about five minutes:

  1. Open console.cloud.google.com and create a project called OtoReader.
  2. APIs & Services → Library: search for Google Drive API and press Enable.
  3. APIs & Services → OAuth consent screen: choose External, app name OtoReader, your email twice, Save. Under Test users add your own Gmail address.
  4. APIs & Services → Credentials → Create credentials → OAuth client ID: type Web application, and under Authorized JavaScript origins add exactly:
  5. Press Create and copy the Client ID (it ends with .apps.googleusercontent.com) into the box below.
